## 📋 Module Breakdown

### 🔹 Module 1: Introduction to Object-Oriented Programming
**Theory:** OOP history, evolution, design principles, procedural vs. OOP, classes & objects, data members & member functions, real-world applications.

**Practical:** Setting up the C++ OOP environment, creating classes/objects, accessing members, multiple objects, real-world examples, compilation & debugging.

---

### 🔹 Module 2: Constructors, Destructors, and Encapsulation
**Theory:** Default/parameterized/copy constructors, constructor overloading, destructors, encapsulation, access specifiers (`public`, `private`, `protected`), getters/setters, `this` pointer, static members, const members, arrays of objects.

**Practical:** Implementing all constructor types, destructors, encapsulation, getters/setters, `this` pointer, static members, const members, arrays of objects.

---

### 🔹 Module 3: Advanced Class Concepts and Object Relationships
**Theory:** Function & operator overloading, friend functions/classes, dynamic memory allocation (`new`/`delete`), class identification, relationships (association, aggregation, composition).

**Practical:** Unary/binary operator overloading (member & friend functions), friend functions/classes, dynamic memory, association, aggregation, composition, real-world relationship design.

---

### 🔹 Module 4: Inheritance and Code Reusability
**Theory:** Base/derived classes, single/multilevel/multiple/hierarchical/hybrid inheritance, access modes, function overriding, constructor/destructor execution order, ambiguity resolution, virtual base classes.

**Practical:** Implementing all inheritance types, access modes, function overriding, constructor/destructor order, ambiguity resolution, virtual base classes.

---

### 🔹 Module 5: Polymorphism and Dynamic Binding
**Theory:** Compile-time vs. runtime polymorphism, function/operator overloading, overriding, virtual & pure virtual functions, dynamic/static binding, virtual destructors, early/late binding.

**Practical:** Compile-time & runtime polymorphism, function/operator overloading, overriding, virtual functions, pure virtual functions, base-class pointers, dynamic binding, virtual destructors.

---

### 🔹 Module 6: Abstraction, Abstract Classes, and Templates
**Theory:** Data abstraction, abstract classes, pure virtual functions, interfaces, function & class templates, template specialization, generic programming, STL (containers, iterators, algorithms).

**Practical:** Data abstraction, abstract classes, interface design, function/class templates, template specialization, STL containers (vectors, lists, stacks, queues, maps), iterators & algorithms.

---

### 🔹 Module 7: String Manipulation and Exception Handling
**Theory:** C++ strings, character arrays vs. `string` class, string functions, exception handling (`try`, `catch`, `throw`), multiple catch blocks, nested handling, user-defined exceptions, stack unwinding, dynamic memory, memory leaks, dangling pointers.

**Practical:** Character arrays, string manipulation, `string` class functions, try-catch blocks, multiple exceptions, user-defined exceptions, nested handling, dynamic memory management, leak identification, dangling pointers.

---

### 🔹 Module 8: File Handling, Streams, and Object Data Storage
**Theory:** File handling, C++ streams (I/O, file I/O), text vs. binary files, reading/writing, file opening modes, object data storage, serialization/deserialization, file position pointers, debugging strategies.

**Practical:** Creating/opening files, reading/writing text files, `ifstream`/`ofstream`/`fstream`, file opening modes, binary files, saving/retrieving objects, file position pointers, debugging.

---

### 🔹 Module 9: GUI Development, Event Handling, and Database Connectivity
**Theory:** GUI fundamentals, C++ GUI development, Qt framework, widgets, layout management, event-driven programming, event handling, signals & slots, database connectivity, Qt SQL, connecting C++ apps to databases.

**Practical:** Qt Creator, GUI apps, windows/widgets, buttons/labels/text fields, layouts, mouse & keyboard events, signals & slots, event-driven apps, SQLite/MySQL connectivity, CRUD operations, database-driven GUIs.
