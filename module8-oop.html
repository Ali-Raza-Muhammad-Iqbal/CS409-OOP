Part A: Theory Topics

1. Introduction to File Handling

Definition: File handling is the process of reading from and writing to files on disk. It allows a program to store data permanently so it survives after the program ends and can be reused in later runs.

Why File Handling Matters

  • Persists data beyond program execution.
  • Allows sharing of data between programs.
  • Supports large volumes of data that cannot fit in memory.
  • Enables logging, reporting, and configuration storage.

Real-Life Example

A student records application saves each student's data in a file so the registrar can retrieve it later, even after the computer is restarted.

2. Introduction to C++ Streams

Definition: A stream in C++ is an abstraction that represents a sequence of bytes flowing between a program and a source or destination. Streams handle the input and output operations uniformly across different devices.

Types of Streams

TypeDescriptionExample
Input streamData flows from source to programcin
Output streamData flows from program to destinationcout
Input-output streamData can flow both waysfstream

Stream Class Hierarchy

ios_base | ios / \ istream ostream / \ / \ ifstream fstream ofstream (input) (both) (output)

Real-Life Example

A pipe carrying water: the flow direction determines whether it is an input pipe (into the house), an output pipe (out of the house), or a two-way pipe.

3. Input and Output Streams

Standard Streams

StreamPurposeHeader
cinStandard input (keyboard)<iostream>

cerrUnbuffered error output<iostream>

Real-Life Example

A customer service desk: input requests come in (cin), answers go out (cout), urgent warnings are announced immediately (cerr), and regular logs are recorded (clog).

4. File Input and Output Streams

Definition: File streams are specialized stream classes that connect a program to files on disk. C++ provides three classes in the <fstream> header: ifstream for input, ofstream for output, and fstream for both.

Classes

ClassPurpose
ifstreamInput file stream; reads from a file
ofstreamOutput file stream; writes to a file
fstreamFile stream for both input and output

Syntax

#include <fstream>

ifstream inFile("input.txt");
ofstream outFile("output.txt");
fstream ioFile("data.txt", ios::in | ios::out);

Real-Life Example

A photocopier that can only read (ifstream), a printer that can only write (ofstream), and a multifunction device that does both (fstream).

5. File Processing

Definition: File processing is the sequence of operations performed on a file: opening it, reading or writing data, checking for errors, and closing it. Following this sequence correctly ensures data integrity.

Steps in File Processing

  1. Include the <fstream> header.
  2. Create a stream object.
  3. Open the file with the desired mode.
  4. Check for successful opening.
  5. Read or write data.
  6. Close the file.

File Processing Flow Diagram

+-----------+ | Include | +-----+-----+ v +-----------+ | Create | | stream | +-----+-----+ v +-----------+ | Open file | +-----+-----+ v +-----------+ | Opened? | --- no ---> Handle error +-----+-----+ | yes v +-----------+ | Read/Write| +-----+-----+ v +-----------+ | Close file| +-----------+

6. Text Files and Binary Files

Text Files

Definition: A text file stores data as human-readable characters. Each value is converted to a character sequence when written and parsed back when read.

Characteristics

  • Readable by humans.
  • Portable across systems.
  • Slightly larger and slower due to conversion.

Binary Files

Definition: A binary file stores data in its raw memory representation. Values are written directly as bytes, without conversion to text.

Characteristics

  • Not human-readable.
  • Faster and more compact.
  • System-specific for some data types (endianness).
  • Ideal for storing objects and numeric records.

Comparison

FeatureText FileBinary File
ReadabilityHuman-readableNot readable directly
SizeLargerSmaller
SpeedSlowerFaster
PortabilityHighSystem dependent
Typical useConfiguration, logs, CSVObjects, images, audio

Real-Life Example

A recipe book (text file) is readable by anyone, while a photograph (binary file) requires an appropriate viewer to interpret.

Real-Life Example

A cashier writes each sale to a receipt file and later the accountant reads the same file for daily totals.

Complete Code Example

#include <iostream>
#include <fstream>
using namespace std;

int main() {
    // Writing
    ofstream out("sample.txt");
    out << "Line one" << endl;
    out << "Line two" << endl;
    out.close();

    string line;
    while (getline(in, line)) {
        cout << line << endl;
    }
    in.close();

    return 0;
}
Output: Line one Line two

8. File Opening Modes

Definition: File opening modes specify how a file should be opened, controlling operations such as reading, writing, appending, and truncating. Modes are defined in the ios class.

Common Modes

ModeDescription
ios::inOpen for reading
ios::outOpen for writing (truncates by default)
ios::appAppend to the end of the file
ios::ateOpen and move to the end
ios::truncTruncate existing content
ios::binaryOpen in binary mode

Combining Modes

fstream file("data.txt", ios::in | ios::out | ios::binary);

Real-Life Example

A notebook can be opened for reading (in), opened to a fresh page (out), or opened at the last written page (app). The mode chosen determines how you interact with it.

9. Object Data Storage

Definition: Object data storage is the process of persisting the state of objects to files so that they can be restored later. It allows programs to save and load complex data structures such as lists of students, products, or transactions.

Approaches

ApproachDescription
Text-basedWrite each attribute as text, separated by spaces or commas
BinaryWrite raw memory bytes of the object using write()

Real-Life Example

A game saves the player's progress (level, score, inventory) to a file so the player can resume later.

Text-based Example

class Student {
public:
    string name;
    int age;
    double gpa;
};

// Writing
ofstream out("students.txt");
out << s.name << " " << s.age << " " << s.gpa << endl;

// Reading
ifstream in("students.txt");
Student s;
in >> s.name >> s.age >> s.gpa;

Binary Example

ofstream out("students.dat", ios::binary);
out.write(reinterpret_cast<char*>(&s), sizeof(s));

ifstream in("students.dat", ios::binary);
in.read(reinterpret_cast<char*>(&s), sizeof(s));

10. Object Serialization and Deserialization Concepts

Serialization: The process of converting an object's state into a format that can be stored (in a file) or transmitted (over a network).

Deserialization: The reverse process, converting stored data back into an object.

Serialization Formats

FormatDescription
Plain textHuman-readable, simple to debug
CSVComma-separated values; common for tabular data
JSON / XMLStructured text formats, widely used in web apps
BinaryRaw byte representation; compact and fast

Real-Life Example

When a user closes a messaging app, the chat history is serialized to storage and later deserialized when reopened, restoring the conversation exactly as it was.

11. File Position Pointers

Definition: File position pointers indicate the current location within a file where the next read or write will occur. Each file stream maintains two pointers: get pointer for reading and put pointer for writing.

Associated Functions

FunctionPurpose
tellg()Returns the current position of the get pointer
tellp()Returns the current position of the put pointer
seekg(pos)Moves the get pointer to the specified position
seekp(pos)Moves the put pointer to the specified position

Real-Life Example

A bookmark in a book marks the exact page where reading resumes. The get pointer is the current page marker, and seekg() moves the bookmark.

Code Example

#include <iostream>
#include <fstream>
using namespace std;

int main() {
    fstream file("seek.txt", ios::in | ios::out | ios::trunc);
    file << "HelloWorld";
    file.seekg(5);
    char ch;
    file.get(ch);
    cout << "Character at position 5: " << ch << endl;
    file.close();
    return 0;
}
Output: Character at position 5: W

12. Debugging Strategies

Common File-Handling Bugs

BugCause
File not openingWrong path, missing permissions, or missing file
Empty outputStream not flushed or file not closed
Garbage dataBinary/text mode mismatch
Infinite loopgetline() not reaching EOF
Data corruptionWriting without a matching layout on read

Debugging Strategies

  1. Always check whether the file opened successfully.
  2. Print stream state using good(), fail(), eof().
  3. Close all files after use to flush buffers.
  4. Use text mode for human-readable output during development.
  5. Log positions using tellg() and tellp() when diagnosing read/write issues.
  6. Use small sample files for testing before scaling to real data.

Real-Life Example

A mechanic listens for unusual sounds, checks the dashboard lights, and reads the diagnostic log before touching the engine. A programmer follows the same principle: inspect the log, check the state, then fix.

Practical 4: Working with ifstream, ofstream, and fstream

#include <iostream>
#include <fstream>
using namespace std;

int main() {
    // ofstream: writing
    ofstream out("demo.txt");
    out << "Line one" << endl;
    out << "Line two" << endl;
    out.close();

    // ifstream: reading
    ifstream in("demo.txt");
    string line;
    while (getline(in, line)) cout << "Read: " << line << endl;
    in.close();

    // fstream: both
    fstream both("demo.txt", ios::in | ios::out | ios::app);
    both << "Line three" << endl;
    both.close();

    ifstream readAgain("demo.txt");
    while (getline(readAgain, line)) cout << "Final: " << line << endl;
    readAgain.close();

    return 0;
}
Output: Read: Line one Read: Line two Final: Line one Final: Line two Final: Line three

Practical 6: Working with Binary Files

#include <iostream>
#include <fstream>
using namespace std;

int main() {
    int numbers[] = {10, 20, 30, 40, 50};

    // Write binary
    ofstream out("nums.bin", ios::binary);
    out.write(reinterpret_cast<char*>(numbers), sizeof(numbers));
    out.close();

    // Read binary
    int readBack[5];
    ifstream in("nums.bin", ios::binary);
    in.read(reinterpret_cast<char*>(readBack), sizeof(readBack));
    in.close();

    cout << "Read: ";
    for (int n : readBack) cout << n << " ";
    cout << endl;

    return 0;
}
Output: Read: 10 20 30 40 50

Practical 7: Saving Object Information into Files

#include <iostream>
#include <fstream>
using namespace std;

class Student {
public:
    string name;
    int age;
    double gpa;
};

int main() {
    Student students[2] = {
        {"Ali", 20, 3.5},
        {"Sara", 21, 3.8}
    };

    ofstream out("students.dat", ios::binary);
    for (int i = 0; i < 2; i++) {
        out.write(reinterpret_cast<char*>(&students[i]), sizeof(Student));
    }
    out.close();
    cout << "Objects saved" << endl;

    return 0;
}
Output: Objects saved
Note: Binary serialization of objects containing strings (as shown) works only when reading back on the same program with the same memory layout. For portable serialization, write each field separately or use a text format such as CSV or JSON.

Practical 8: Retrieving Object Information from Files

#include <iostream>
#include <fstream>
using namespace std;

class Student {
public:
    string name;
    int age;
    double gpa;
};

int main() {
    Student s;
    ifstream in("students.dat", ios::binary);
    while (in.read(reinterpret_cast<char*>(&s), sizeof(Student))) {
        cout << s.name << " | " << s.age << " | " << s.gpa << endl;
    }
    in.close();
    return 0;
}
Output: Ali | 20 | 3.5 Sara | 21 | 3.8

Practical 9: Using File Position Pointers

#include <iostream>
#include <fstream>
using namespace std;

int main() {
    fstream file("seektest.txt", ios::in | ios::out | ios::trunc);
    file << "ABCDEFGHIJ";
    file.seekg(0);

    cout << "Read all: ";
    char ch;
    while (file.get(ch)) cout << ch;
    cout << endl;

    file.clear();                  // reset after EOF
    file.seekg(4, ios::beg);
    file.get(ch);
    cout << "Character at position 4: " << ch << endl;

    file.seekp(2, ios::beg);
    file.put('X');

    file.clear();
    file.seekg(0);
    cout << "After change: ";
    while (file.get(ch)) cout << ch;
    cout << endl;

    file.close();
    return 0;
}
Output: Read all: ABCDEFGHIJ Character at position 4: E After change: ABXDEFGHIJ

Practical 10: Debugging File-Handling Programs

#include <iostream>
#include <fstream>
using namespace std;

int main() {
    ifstream in("missing.txt");

    if (!in) {
        cerr << "Error: unable to open missing.txt" << endl;
        return 1;
    }

    string line;
    int lineCount = 0;
    while (getline(in, line)) {
        lineCount++;
        cout << "Line " << lineCount << ": " << line << endl;
    }

    if (in.eof())
        cout << "Reached end of file normally" << endl;
    else if (in.fail())
        cout << "Read failed due to format or I/O issue" << endl;

    in.close();
    return 0;
}
Output: Error: unable to open missing.txt
