Part A: Theory Topics

1. Introduction to Graphical User Interfaces (GUI)

Definition: A Graphical User Interface (GUI) is a visual interface that allows users to interact with a program through graphical elements such as windows, buttons, menus, icons, and text fields, instead of typing commands on a text console.

Advantages of GUI

  • Intuitive and easy to learn for non-technical users.
  • Visual feedback improves user experience.
  • Supports multitasking through multiple windows.
  • Reduces the need to memorize commands.
  • Enables richer interaction through mouse, keyboard, and touch.

Real-Life Example

An ATM machine presents a touch screen with buttons for "Withdraw," "Deposit," and "Balance." The user does not type commands; they tap visual options, which is the essence of a GUI.

2. GUI Development in C++

Definition: GUI development in C++ involves using a GUI framework or library to create windows, widgets, and event-driven behavior. Unlike console applications, GUI programs wait for user actions and respond to them.

Popular C++ GUI Frameworks

FrameworkDescription
QtCross-platform, mature, supports widgets and QML
wxWidgetsNative look and feel on each platform
GTKmmC++ wrapper for GTK
Dear ImGuiImmediate-mode GUI, popular for tools and games

Real-Life Example

Building a desktop calculator app where the user clicks numbered buttons and sees the result appear instantly in a display area.

3. Introduction to the Qt Framework

Definition: Qt is a comprehensive cross-platform C++ framework for developing GUI applications, networking tools, and database-driven software. It provides a rich set of widgets, an event system, and the signal-slot mechanism.

Key Features of Qt

  • Cross-platform: runs on Windows, Linux, macOS, and embedded systems.
  • Object-oriented design built on QObject.
  • Signal-slot mechanism for communication between objects.
  • Qt SQL module for database connectivity.
  • Qt Creator IDE for rapid development.

Real-Life Example

Qt powers applications such as Autodesk Maya, Telegram Desktop, and the KDE desktop environment. It is chosen when an application must run identically on multiple operating systems.

4. GUI Components and Widgets

Definition: Widgets are the basic building blocks of a Qt GUI. Each widget is a visual element that the user can see or interact with. Common widgets include buttons, labels, text fields, checkboxes, and combo boxes.

A login form uses a QLabel for "Username," a QLineEdit for typing the name, and a QPushButton for "Login." Each is a widget working together.

5. Layout Management

6. Event-Driven Programming

Definition: Event-driven programming is a programming paradigm in which the flow of the program is determined by events such as mouse clicks, key presses, or timer expirations. Instead of running top-to-bottom, the program waits for events and responds through event handlers.

Event Loop Concept

+------------------+ | Event Loop | | (runs forever) | +--------+---------+ | event occurs? / \ yes no | | v v dispatch wait to handler

Real-Life Example

A television remote control waits for a button press (event), then responds by changing the channel (handler). The TV does nothing until the user acts.

7. Event Handling Mechanism

Definition: Event handling is the process by which a GUI program detects events, dispatches them to the appropriate handler, and performs the corresponding action. In Qt, events are represented as objects derived from QEvent.

Types of Events

Event TypeDescription
Mouse eventsClick, double-click, move, press, release
Keyboard eventsKey press, key release
Window eventsResize, move, close
Timer eventsPeriodic timeouts

Handler Functions in Qt

void mousePressEvent(QMouseEvent *event);
void keyPressEvent(QKeyEvent *event);
void resizeEvent(QResizeEvent *event);

Real-Life Example

When a user clicks a "Save" button, the mouse press event is dispatched to the button's handler, which triggers the save action.

8. Signals and Slots in Qt

Definition: Signals and slots are Qt's mechanism for communication between objects. A signal is emitted when a particular event occurs; a slot is a function that is called in response to a signal. The connection is made with QObject::connect() [citation:2][citation:11].

Key Concepts

  • A class using signals and slots must inherit from QObject and include the Q_OBJECT macro [citation:2].
  • Signals are declared under the signals: keyword and require no implementation.
  • Slots are declared under public slots: or private slots:.
  • The emit keyword triggers a signal [citation:2].

Connection Types

TypeBehavior
Qt::DirectConnectionSlot runs immediately in the emitting thread [citation:2]
Qt::QueuedConnectionSlot runs later in the receiver's event loop [citation:2]
Qt::AutoConnectionChooses direct or queued based on thread affinity (default) [citation:2]

Real-Life Example

A smoke detector (signal) triggers an alarm (slot). The detector does not know or care what the alarm does; it simply emits the signal, and the connected alarm responds.

Syntax

class MyClass : public QObject {
    Q_OBJECT
public slots:
    void handleEvent(int value);
signals:
    void valueChanged(int value);
};

// Connecting
QObject::connect(sender, &Sender::signalName,
                 receiver, &Receiver::slotName);

9. Introduction to Database Connectivity

Definition: Database connectivity is the ability of an application to connect to a database management system, send queries, and retrieve results. It allows the application to store, update, and query persistent data.

Why GUI Applications Need Databases

  • Store user records, transactions, and settings.
  • Retrieve large amounts of structured data.
  • Support multiple users accessing shared data.
  • Ensure data integrity through transactions.

Real-Life Example

A hospital reception GUI looks up patient records from a central database as the receptionist types a name, displaying results instantly.

10. Database Connectivity Using Qt SQL

Real-Life Example

A point-of-sale GUI connects to a MySQL database on a local server. Each sale is inserted into a transactions table, and daily reports are generated by querying the same table.

11. Connecting C++ Applications with Databases

General Steps

  1. Add the SQL module to the project file: QT += sql [citation:3][citation:9].
  2. Include the necessary headers: <QSqlDatabase>, <QSqlQuery>, <QSqlError> [citation:9].
  3. Load the appropriate driver using QSqlDatabase::addDatabase() [citation:3].
  4. Set connection parameters (host, database name, user, password) [citation:3].
  5. Open the connection with db.open() and check for errors [citation:3].
  6. Execute queries using QSqlQuery [citation:9].
  7. Close the connection when done.

Connection Diagram

C++ GUI Application | v QSqlDatabase::addDatabase(driver) | v Set host, database, user, password | v db.open() | v QSqlQuery::exec("SQL statement") | v Process results / handle errors

Practical 6: Handling Mouse and Keyboard Events

#include <QApplication>
#include <QWidget>
#include <QMouseEvent>
#include <QKeyEvent>
#include <QDebug>

class MyWidget : public QWidget {
protected:
    void mousePressEvent(QMouseEvent *event) override {
        qDebug() << "Mouse pressed at:" << event->pos();
    }

    void keyPressEvent(QKeyEvent *event) override {
        qDebug() << "Key pressed:" << event->key();
        if (event->key() == Qt::Key_Escape)
            close();
    }
};

int main(int argc, char *argv[]) {
    QApplication app(argc, argv);
    MyWidget w;
    w.resize(400, 300);
    w.show();
    return app.exec();
}
Note: Clicking the widget must give it focus for keyboard events to be received. Call setFocus() in the mouse press handler if needed.

Practical 7: Implementing Signals and Slots

#include <QApplication>
#include <QWidget>
#include <QPushButton>
#include <QLabel>
#include <QVBoxLayout>

class MyWindow : public QWidget {
    Q_OBJECT
public:
    MyWindow() {
        QVBoxLayout *layout = new QVBoxLayout(this);

        label = new QLabel("Not clicked yet");
        button = new QPushButton("Click Me");

        layout->addWidget(label);
        layout->addWidget(button);

        connect(button, &QPushButton::clicked,
                this, &MyWindow::onButtonClicked);
    }

private slots:
    void onButtonClicked() {
        label->setText("Button was clicked!");
    }

private:
    QLabel *label;
    QPushButton *button;
};

int main(int argc, char *argv[]) {
    QApplication app(argc, argv);
    MyWindow w;
    w.show();
    return app.exec();
}

#include "main.moc"
Output: A window with a label and button. Clicking the button changes the label text to "Button was clicked!"

Practical 8: Developing Event-Driven Applications

#include <QApplication>
#include <QWidget>
#include <QPushButton>
#include <QLabel>
#include <QVBoxLayout>

class CounterApp : public QWidget {
    Q_OBJECT
public:
    CounterApp() : count(0) {
        QVBoxLayout *layout = new QVBoxLayout(this);

        display = new QLabel("0");
        incrementBtn = new QPushButton("+1");
        resetBtn = new QPushButton("Reset");

        layout->addWidget(display);
        layout->addWidget(incrementBtn);
        layout->addWidget(resetBtn);

        connect(incrementBtn, &QPushButton::clicked,
                this, &CounterApp::increment);
        connect(resetBtn, &QPushButton::clicked,
                this, &CounterApp::reset);
    }

private slots:
    void increment() {
        count++;
        display->setText(QString::number(count));
    }
    void reset() {
        count = 0;
        display->setText("0");
    }

private:
    int count;
    QLabel *display;
    QPushButton *incrementBtn;
    QPushButton *resetBtn;
};

int main(int argc, char *argv[]) {
    QApplication app(argc, argv);
    CounterApp w;
    w.show();
    return app.exec();
}

#include "main.moc"
Output: A counter that increments when "+1" is clicked and resets to 0 when "Reset" is clicked.

Practical 9: Connecting C++ Applications with SQLite or MySQL

SQLite Connection (No Server Required)

#include <QCoreApplication>
#include <QSqlDatabase>
#include <QSqlQuery>
#include <QSqlError>
#include <QDebug>

int main(int argc, char *argv[]) {
    QCoreApplication app(argc, argv);

    QSqlDatabase db = QSqlDatabase::addDatabase("QSQLITE");
    db.setDatabaseName("mydata.db");

    if (!db.open()) {
        qDebug() << "Error:" << db.lastError().text();
        return -1;
    }

    qDebug() << "SQLite connected";
    db.close();
    return 0;
}

MySQL Connection (Server Required)

QSqlDatabase db = QSqlDatabase::addDatabase("QMYSQL");
db.setHostName("localhost");
db.setPort(3306);
db.setDatabaseName("testdb");
db.setUserName("root");
db.setPassword("password");

if (!db.open()) {
    qDebug() << "MySQL error:" << db.lastError().text();
    return -1;
}
Note: For MySQL, the Qt MySQL driver must be installed and the MySQL client library must be available on the system [citation:9][citation:24]. SQLite works out of the box with Qt [citation:3].

Practical 10: Performing CRUD Operations

#include <QCoreApplication>
#include <QSqlDatabase>
#include <QSqlQuery>
#include <QSqlError>
#include <QDebug>

int main(int argc, char *argv[]) {
    QCoreApplication app(argc, argv);

    QSqlDatabase db = QSqlDatabase::addDatabase("QSQLITE");
    db.setDatabaseName("crud.db");
    if (!db.open()) { qDebug() << db.lastError().text(); return -1; }

    QSqlQuery query;

    // CREATE table
    query.exec("CREATE TABLE IF NOT EXISTS users "
               "(id INTEGER PRIMARY KEY, name TEXT, age INTEGER)");

    // INSERT
    query.prepare("INSERT INTO users (name, age) VALUES (?, ?)");
    query.addBindValue("Alice");
    query.addBindValue(30);
    query.exec();

    query.prepare("INSERT INTO users (name, age) VALUES (?, ?)");
    query.addBindValue("Bob");
    query.addBindValue(25);
    query.exec();

    // READ
    query.exec("SELECT * FROM users");
    qDebug() << "--- Users ---";
    while (query.next()) {
        qDebug() << query.value("id").toInt()
                 << query.value("name").toString()
                 << query.value("age").toInt();
    }

    // UPDATE
    query.prepare("UPDATE users SET age = ? WHERE name = ?");
    query.addBindValue(31);
    query.addBindValue("Alice");
    query.exec();

    // DELETE
    query.prepare("DELETE FROM users WHERE name = ?");
    query.addBindValue("Bob");
    query.exec();

    // Verify
    query.exec("SELECT * FROM users");
    qDebug() << "--- After Update/Delete ---";
    while (query.next()) {
        qDebug() << query.value("name").toString()
                 << query.value("age").toInt();
    }

    db.close();
    return 0;
}
Output (console): --- Users --- 1 "Alice" 30 2 "Bob" 25 --- After Update/Delete --- "Alice" 31

Practical 11: Developing Database-Driven GUI Applications

#include <QApplication>
#include <QWidget>
#include <QTableView>
#include <QVBoxLayout>
#include <QSqlDatabase>
#include <QSqlTableModel>
#include <QSqlError>

int main(int argc, char *argv[]) {
    QApplication app(argc, argv);

    QSqlDatabase db = QSqlDatabase::addDatabase("QSQLITE");
    db.setDatabaseName("crud.db");
    if (!db.open()) { return -1; }

    QSqlTableModel *model = new QSqlTableModel;
    model->setTable("users");
    model->select();
    model->setEditStrategy(QSqlTableModel::OnFieldChange);

    QTableView *view = new QTableView;
    view->setModel(model);
    view->resize(500, 300);
    view->show();

    return app.exec();
}
Output: A window displaying the users table in a grid. Edits made in the table are automatically saved to the database.
