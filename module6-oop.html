Part A: Theory Topics

1. Introduction to Abstraction

Definition: Abstraction is the process of hiding the internal implementation details of a system and exposing only the essential features to the user. It focuses on what an object does rather than how it does it.

Purpose of Abstraction

  • Reduces complexity by hiding unnecessary detail.
  • Allows users to interact with an object through a simple interface.
  • Protects internal data and logic from outside interference.
  • Enables the implementation to change without affecting users.

Real-Life Example

When driving a car, the driver uses the steering wheel, accelerator, and brakes. The internal combustion process, fuel injection, and transmission mechanics are hidden. The driver only interacts with the essential controls.

Abstraction vs Encapsulation

AspectAbstractionEncapsulation

FocusWhat the object doesHow data is protected
ImplementationAbstract classes, interfacesAccess specifiers, getters and setters
LevelDesign levelImplementation level

2. Data Abstraction in C++

Definition: Data abstraction in C++ is achieved by exposing only the required operations on data through public member functions while keeping the data itself private or protected.

How C++ Supports Data Abstraction

  • Using classes with private or protected data members.
  • Providing public member functions for controlled access.
  • Using abstract classes with pure virtual functions.
  • Using header files to hide implementation details from the user.

Real-Life Example

When you withdraw money from an ATM, you interact with a simple screen and buttons. The banking database, transaction processing, and security checks remain hidden behind the interface.

Code Example

#include <iostream>
using namespace std;

class BankAccount {
private:
    double balance;                          // hidden data

public:
    BankAccount(double initial) { balance = initial; }

    void deposit(double amount) {
        if (amount > 0) balance += amount;
    }

    void withdraw(double amount) {
        if (amount > 0 && amount <= balance) balance -= amount;
    }

    double getBalance() const { return balance; }
};

int main() {
    BankAccount acc(1000);
    acc.deposit(500);
    acc.withdraw(300);
    cout << "Balance: $" << acc.getBalance() << endl;
    return 0;
}
Output: Balance: $1200

3. Abstract Classes

Definition: An abstract class is a class that contains at least one pure virtual function. It cannot be instantiated directly and serves as a base class that defines a common interface for derived classes.

Key Points

  • Declared with at least one pure virtual function (= 0).
  • Cannot create objects of an abstract class.
  • Can contain normal member functions, constructors, and data members.
  • Derived classes must implement all pure virtual functions to become concrete.
  • Pointers and references to abstract classes are allowed.

Real-Life Example

The concept of a "Vehicle" is abstract. There is no generic vehicle on the road; only specific vehicles such as cars, buses, and bikes exist. Yet all share the common concept "Vehicle".

Syntax

class AbstractClass {
public:
    virtual returnType functionName(parameters) = 0;   // pure virtual
    // normal members may also exist
};

4. Pure Virtual Functions

Definition: A pure virtual function is a virtual function declared in a base class with the syntax = 0 instead of a function body. It defines an interface that derived classes must implement.

Syntax

virtual returnType functionName(parameters) = 0;

Rules

  • A class containing a pure virtual function becomes abstract.
  • The pure virtual function may still be defined outside the class if needed.
  • Derived classes must override all pure virtual functions to be instantiable.

Real-Life Example

Every "Appliance" has an "operate" action, but no one can operate a generic appliance. Washing machines, microwaves, and refrigerators each implement operate() in their own way.

Code Example

#include <iostream>
using namespace std;

class Appliance {
public:
    virtual void operate() = 0;              // pure virtual
};

class WashingMachine : public Appliance {
public:
    void operate() override { cout << "Washing clothes" << endl; }
};

class Microwave : public Appliance {
public:
    void operate() override { cout << "Heating food" << endl; }
};

int main() {
    Appliance *a1 = new WashingMachine();
    Appliance *a2 = new Microwave();
    a1->operate();
    a2->operate();
    delete a1;
    delete a2;
    return 0;
}
Output: Washing clothes Heating food

5. Interfaces Using Abstract Classes

Definition: An interface in C++ is an abstract class that contains only pure virtual functions and no data members. It defines a contract that any derived class must fulfill.

Characteristics of an Interface

  • All member functions are pure virtual.
  • No data members (or only static constant members).
  • A class may implement multiple interfaces through multiple inheritance.
  • Provides a standard way for unrelated classes to share a common contract.

Real-Life Example

USB is an interface standard. Keyboards, mice, printers, and storage drives all implement the USB contract so they can plug into any USB port.

Syntax

class InterfaceName {
public:
    virtual returnType function1() = 0;
    virtual returnType function2() = 0;
};

Code Example

#include <iostream>
using namespace std;

class Printable {
public:
    virtual void print() = 0;
};

class Scannable {
public:
    virtual void scan() = 0;
};

class AllInOnePrinter : public Printable, public Scannable {
public:
    void print() override { cout << "Printing document" << endl; }
    void scan() override { cout << "Scanning document" << endl; }
};

int main() {
    AllInOnePrinter p;
    p.print();
    p.scan();
    return 0;
}
Output: Printing document Scanning document

6. Introduction to Templates

Definition: A template in C++ is a blueprint for creating generic functions or classes that work with any data type. The compiler generates the specific code for the data type actually used.

Advantages of Templates

  • Code reusability across multiple data types.
  • Type safety maintained by the compiler.
  • No runtime overhead (unlike polymorphism via virtual functions).
  • Enables generic programming.

Real-Life Example

A photocopier can copy any document: letters, photographs, or diagrams. The process of copying is identical, and only the input changes. A template works the same way.

Types of Templates

TypeDescription
Function templateA single function that works with multiple data types
Class templateA single class definition that works with multiple data types

7. Function Templates

Definition: A function template is a generic function definition that is instantiated for different data types. The type is supplied when the function is called or deduced by the compiler.

Syntax

template <typename T>
returnType functionName(T param1, T param2) {
    // uses T as data type
}

Real-Life Example

A "maximum" function that works for integers, decimals, or characters without writing three separate functions.

Code Example

#include <iostream>
using namespace std;

template <typename T>
T maximum(T a, T b) {
    return (a > b) ? a : b;
}

int main() {
    cout << maximum(10, 20) << endl;
    cout << maximum(3.14, 2.71) << endl;
    cout << maximum('a', 'z') << endl;
    return 0;
}
Output: 20 3.14 z

8. Class Templates

Definition: A class template is a generic class definition in which one or more data types are parameterized. It allows creation of type-safe containers and reusable components that work with any data type.

Syntax

template <typename T>
class ClassName {
    T member;
public:
    void set(T value) { member = value; }
    T get() { return member; }
};

Real-Life Example

A storage box can hold any kind of item: books, shoes, or tools. The box design is the same; only its contents change. A class template is like a box that can hold any type.

Code Example

#include <iostream>
using namespace std;

template <typename T>
class Box {
private:
    T item;
public:
    Box(T value) : item(value) { }
    T getItem() { return item; }
};

int main() {
    Box<int> intBox(100);
    Box<double> dblBox(3.14);
    Box<string> strBox("Hello");

    cout << intBox.getItem() << endl;
    cout << dblBox.getItem() << endl;
    cout << strBox.getItem() << endl;

    return 0;
}
Output: 100 3.14 Hello

9. Template Overloading and Specialization

Template Overloading

Definition: Template overloading means defining multiple function templates with the same name but different parameter lists, or combining a template function with a regular function of the same name.

Example

template <typename T>
T add(T a, T b) { return a + b; }

template <typename T>
T add(T a, T b, T c) { return a + b + c; }

int add(int a, int b) { return a + b; }      // non-template overload

Template Specialization

Definition: Template specialization provides a specific implementation of a template for a particular data type. When that data type is used, the specialized version replaces the generic one.

Types of Specialization

TypeDescription
Full specializationA specific implementation for one exact data type
Partial specializationA specific implementation when one or more (but not all) template parameters are fixed

Real-Life Example

A delivery service has one standard procedure for packages, but a special procedure for fragile items such as glassware. The default behavior works for most packages; a special case exists for glass.

Code Example

#include <iostream>
using namespace std;

template <typename T>
T maximum(T a, T b) {
    return (a > b) ? a : b;
}

// Full specialization for const char*
template <>
const char* maximum(const char* a, const char* b) {
    return (string(a).length() > string(b).length()) ? a : b;
}

int main() {
    cout << maximum(10, 20) << endl;
    cout << maximum("Cat", "Elephant") << endl;
    return 0;
}
Output: 20 Elephant

10. Generic Programming

Definition: Generic programming is a programming paradigm in which algorithms and data structures are written in terms of types to be specified later. The goal is to write code that works correctly and efficiently for any appropriate data type.

Principles of Generic Programming

  • Algorithms are written independently of specific data types.
  • Templates are the primary tool in C++.
  • Code is reused across many types with no runtime overhead.
  • Type safety is maintained at compile time.

Real-Life Example

A sorting algorithm works on any data type that supports comparison: integers, names, prices, or dates. The algorithm does not need to be rewritten for each type.

Generic vs Non-Generic Code

AspectNon-GenericGeneric
Code sizeDuplicated for each typeWritten once
MaintenanceUpdate every duplicateUpdate in one place
Type safetyManualEnforced by compiler
PerformanceNo overheadNo overhead (compile-time instantiation)

11. Standard Template Library (STL)

Definition: The Standard Template Library (STL) is a collection of generic classes and functions in C++ that implement commonly used data structures and algorithms. It provides ready-to-use components such as containers, iterators, and algorithms.

12. STL Containers, Iterators, and Algorithms

Containers

Definition: A container is a class template that stores a collection of objects. Containers manage memory automatically and provide member functions to add, remove, and access elements.

Iterators

Definition: An iterator is an object that points to an element inside a container and allows movement between elements. Iterators provide a uniform way to traverse any container.

Definition: Algorithms are generic functions that perform operations on ranges defined by iterators. They are independent of the container used.

Practical 2: Creating Abstract Classes and Pure Virtual Functions

#include <iostream>
using namespace std;

class Shape {
public:
    virtual double area() = 0;      // pure virtual
    virtual void display() = 0;

    virtual ~Shape() { }
};

class Circle : public Shape {
private:
    double radius;
public:
    Circle(double r) : radius(r) { }

    double area() override { return 3.14159 * radius * radius; }
    void display() override {
        cout << "Circle area: " << area() << endl;
    }
};

class Rectangle : public Shape {
private:
    double length, width;
public:
    Rectangle(double l, double w) : length(l), width(w) { }

    double area() override { return length * width; }
    void display() override {
        cout << "Rectangle area: " << area() << endl;
    }
};

int main() {
    Shape *s1 = new Circle(5);
    Shape *s2 = new Rectangle(4, 6);

    s1->display();
    s2->display();

    delete s1;
    delete s2;
    return 0;
}
Output: Circle area: 78.5398 Rectangle area: 24

Practical 3: Designing Interface-Like Structures Using Abstract Classes

#include <iostream>
using namespace std;

class Printable {
public:
    virtual void print() = 0;
    virtual ~Printable() { }
};

class Serializable {
public:
    virtual void serialize() = 0;
    virtual ~Serializable() { }
};

    d.print();
    d.serialize();
    return 0;
}

Practical 4: Creating Function and Class Templates

Function Template

    return (a > b) ? a : b;
}

int main() {

    return 0;
}
Output: 25 3.5 banana

Class Template

#include <iostream>
using namespace std;

template <typename T>
class Stack {
private:
    T items[100];
    int top;
public:
    Stack() { top = -1; }

    void push(T value) {
        if (top < 99) items[++top] = value;
    }

    T pop() {
        if (top >= 0) return items[top--];
        return T();
    }

    bool empty() { return top == -1; }
};

int main() {
    Stack<int> intStack;
    intStack.push(10);
    intStack.push(20);
    cout << intStack.pop() << endl;

    Stack<string> strStack;
    strStack.push("Hello");
    strStack.push("World");
    cout << strStack.pop() << endl;

    return 0;
}
Output: 20 World

#include <iostream>
using namespace std;

class Printer {

    void show(T value) {
        cout << "Value: " << value << endl;
    }
};

// Full specialization for bool

    p1.show(42);
    p2.show(true);

    return 0;
}

Practical 7: Working with STL Iterators and Algorithms

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> nums = {4, 2, 9, 1, 7, 3};

    sort(nums.begin(), nums.end());
    cout << "Sorted: ";
    for (int n : nums) cout << n << " ";
    cout << endl;

    reverse(nums.begin(), nums.end());
    cout << "Reversed: ";
    for (int n : nums) cout << n << " ";
    cout << endl;

    auto it = find(nums.begin(), nums.end(), 7);
    if (it != nums.end())
        cout << "Found 7 at index: " << (it - nums.begin()) << endl;

    int countNines = count(nums.begin(), nums.end(), 9);
    cout << "Count of 9: " << countNines << endl;

    cout << "Max element: " << *max_element(nums.begin(), nums.end()) << endl;

    return 0;
}
Output: Sorted: 1 2 3 4 7 9 Reversed: 9 7 4 3 2 1 Found 7 at index: 1 Count of 9: 1 Max element: 9
