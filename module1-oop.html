1. Introduction to Object-Oriented Programming

Definition: Object-Oriented Programming (OOP) is a programming paradigm that organizes software design around objects rather than functions. It models real-world entities as objects that contain both data (attributes) and behavior (methods).

In simple words, OOP is a way of writing programs where we create objects that represent real-world things, such as a Car, a Student, or a Bank Account, each having its own data and actions.

Syntax (Basic Structure)

class ClassName {
    // data members (attributes)
    // member functions (behaviors)
};

Real-Life Example

Consider a Car:

  • Data (attributes): color, brand, speed, fuel level
  • Behavior (methods): start(), accelerate(), brake()

In OOP, we define a Car class and then create objects such as myCar and yourCar from it.

3. Object-Oriented Design (OOD)

Definition: Object-Oriented Design is the process of planning a software system by identifying objects, their attributes, behaviors, and relationships before writing code.

Steps in Object-Oriented Design

  1. Identify objects from the problem statement.
  2. Define the attributes (data) of each object.
  3. Define the behaviors (methods) of each object.
  4. Define relationships between objects.
  5. Design classes and interfaces.

6. Basic Principles of OOP (The Four Pillars)

+----------------------------+ | 4 PILLARS OF OOP | +-------------+--------------+ +----------+----+----+----------+ v v v v +---------+ +--------+ +--------+ +-----------+ |Encapsu- | |Abstrac-| | Inheri-| | Poly- | | lation | | tion | | tance | | morphism | +---------+ +--------+ +--------+ +-----------+

Pillar 1: Encapsulation

Definition: Encapsulation is the binding of data and methods together in a single unit (a class) while hiding the data from direct access. 
class BankAccount {
private:
    double balance;                              // hidden data
public:
    void deposit(double amt) { balance += amt; } // controlled access
    double getBalance() { return balance; }
};

Pillar 2: Abstraction

Definition: Abstraction is the process of hiding complex implementation details and showing only the essential features of an object. 
class Car {
public:
    void start() { /* complex engine logic hidden */ }
    void brake() { /* complex braking logic hidden */ }
};

Pillar 3: Inheritance

Definition: Inheritance is the mechanism by which one class acquires the properties and methods of another class. 
class Animal {                     // base class
public:
    void eat() { cout << "Eating..." << endl; }
};

class Dog : public Animal {        // derived class
public:
    void bark() { cout << "Barking..." << endl; }
};

Pillar 4: Polymorphism

Definition: Polymorphism means "one name, many forms." The same function behaves differently depending on the object that invokes it. 
class Shape {
public:
    virtual void draw() { cout << "Drawing shape" << endl; }
};

class Circle : public Shape {
public:
    void draw() override { cout << "Drawing circle" << endl; }
};

7. Classes and Objects

Class: A blueprint or template that defines the data members and member functions of a type.

Object: An instance of a class. It is a real entity created from the class.
Analogy: A class is like a cookie cutter, and objects are the cookies made from it.

Syntax

// Class definition
class ClassName {
    access_specifier:
        data_type member1;
        return_type function1() { }
};

// Object creation
ClassName objectName;

Real-Life Example

  • Class: Student
  • Objects: ali, sara, john

Simple Code Example

#include <iostream>
using namespace std;

class Student {
public:
    string name;
    int age;

    void display() {
        cout << "Name: " << name << ", Age: " << age << endl;
    }
};

int main() {
    Student s1;              // object creation
    s1.name = "Ali";
    s1.age = 20;
    s1.display();            // Name: Ali, Age: 20
    return 0;
}
Output: Name: Ali, Age: 20

8. Data Members and Member Functions

Data Members: Variables declared inside a class that store an object's attributes.

Member Functions: Functions declared inside a class that define an object's behaviors.

Syntax

class ClassName {
    data_type dataMember;             // data member
    return_type memberFunction() {    // member function
        // code
    }
};

Types of Data Members

TypeDescription
Instance variablesUnique to each object (non-static)
Static variablesShared by all objects of the class (static)
Constant membersValues that cannot be changed (const)

Real-Life Example

For a Mobile class:

  • Data members: brand, price, battery
  • Member functions: call(), charge(), message()

Code Example 1: Basic Data Members and Member Functions

class Mobile {
private:
    string brand;
    int price;
public:
    void setData(string b, int p) { brand = b; price = p; }
    void display() { cout << brand << " costs " << price << endl; }
};

Code Example 2: Static Data Member

class Counter {
public:
    static int count;        // shared by all objects
    Counter() { count++; }
};
int Counter::count = 0;      // definition outside class

Code Example 3: Constructor (Special Member Function)

class Box {
public:
    int length;
    Box() { length = 10; }   // constructor
    void show() { cout << length; }
};

Practical 3: Defining Data Members and Member Functions

Code Example (Definition Outside the Class)

#include <iostream>
using namespace std;

class Circle {
private:
    double radius;               // data member

public:
    void setRadius(double r);    // declared
    double area();               // declared
};

void Circle::setRadius(double r) { radius = r; }   // defined outside
double Circle::area() { return 3.14 * radius * radius; }

int main() {
    Circle c;
    c.setRadius(5);
    cout << "Area = " << c.area() << endl;
    return 0;
}
Output: Area = 78.5

Practical 4: Accessing Class Members

Two Ways to Access Members

  1. Dot operator (.) used with objects.
  2. Arrow operator (->) used with pointers to objects.

Syntax

object.member;        // dot operator
pointer->member;      // arrow operator

Code Example

#include <iostream>
using namespace std;

class Book {
public:
    string title;
    void show() { cout << "Title: " << title << endl; }
};

int main() {
    Book b;
    b.title = "C++ Basics";       // dot operator
    b.show();

    Book* ptr = &b;
    cout << "Pointer: " << ptr->title << endl;   // arrow operator
    ptr->show();

    return 0;
}
Output: Title: C++ Basics Pointer: C++ Basics Title: C++ Basics

Practical 6: Implementing Real-World Examples Using Classes and Objects

Example 1: Bank Account

#include <iostream>
using namespace std;

class BankAccount {
private:
    string owner;
    double balance;

public:
    void create(string name, double amt) {
        owner = name;
        balance = amt;
    }
    void deposit(double amt) { balance += amt; }
    void withdraw(double amt) {
        if (amt <= balance) balance -= amt;
        else cout << "Insufficient balance!" << endl;
    }
    void show() {
        cout << owner << "'s Balance: $" << balance << endl;
    }
};

int main() {
    BankAccount acc;
    acc.create("Ali", 1000);
    acc.deposit(500);
    acc.withdraw(300);
    acc.show();
    return 0;
}
Output: Ali's Balance: $1200

Example 2: Student Record

#include <iostream>
using namespace std;

class Student {
private:
    string name;
    int roll;
    float marks;

public:
    void input(string n, int r, float m) {
        name = n; roll = r; marks = m;
    }
    void result() {
        cout << "Name: " << name << ", Roll: " << roll
             << ", Marks: " << marks << endl;
    }
};

int main() {
    Student s1, s2;
    s1.input("Sara", 1, 85.5);
    s2.input("John", 2, 72.0);
    s1.result();
    s2.result();
    return 0;
}
Output: Name: Sara, Roll: 1, Marks: 85.5 Name: John, Roll: 2, Marks: 72

Debugging Tips

  1. Compile frequently after each small change.
  2. Read error messages from top to bottom.
  3. Add cout statements to trace values.
  4. Use the IDE debugger with breakpoints and step-through.
  5. Check scope: private members cannot be accessed outside the class.
