Part A: Theory Topics

1. Introduction to Constructors

Definition: A constructor is a special member function of a class that is automatically called when an object is created. Its primary purpose is to initialize the object's data members.

Key Characteristics

  • Has the same name as the class.
  • Has no return type (not even void).
  • Called automatically at the time of object creation.
  • Can be overloaded (multiple constructors with different parameters).
  • Cannot be called explicitly like normal functions.

Syntax

class ClassName {
public:
    ClassName() {
        // constructor body
    }
};

Real-Life Example

When a new bank account is opened, the system automatically fills in details such as account number and opening balance. The constructor performs this automatic setup.

Simple Code Example

#include <iostream>
using namespace std;

class Student {
public:
    string name;
    Student() {
        name = "Unknown";
        cout << "Constructor called" << endl;
    }
};

int main() {
    Student s1;
    cout << "Name: " << s1.name << endl;
    return 0;
}
Output: Constructor called Name: Unknown

2. Default Constructors

Definition: A default constructor is a constructor that takes no parameters. It initializes objects with default values. If no constructor is defined by the programmer, the compiler generates a default constructor automatically.

Types

TypeDescription
Compiler-generated default constructorAutomatically created by the compiler when no constructor is declared. Does not initialize data members (they contain garbage values).
Programmer-defined default constructorWritten by the programmer to assign specific default values.

Syntax

ClassName() {
    // default initialization
}

Real-Life Example

A new mobile phone comes with factory default settings (language, wallpaper, brightness) before the user changes anything.

Code Example

#include <iostream>
using namespace std;

class Mobile {
public:
    string brand;
    int battery;

    Mobile() {              // default constructor
        brand = "Generic";
        battery = 100;
    }

    void show() {
        cout << brand << " - " << battery << "%" << endl;
    }
};

int main() {
    Mobile m;
    m.show();
    return 0;
}
Output: Generic - 100%

3. Parameterized Constructors

Definition: A parameterized constructor is a constructor that accepts arguments. It allows objects to be initialized with specific values at the time of creation.

Syntax

ClassName(dataType param1, dataType param2) {
    member1 = param1;
    member2 = param2;
}

Real-Life Example

When opening a bank account, you provide your name and initial deposit. These values are passed to the constructor, which sets up the account accordingly.

Code Example

#include <iostream>
using namespace std;

class Account {
public:
    string owner;
    double balance;

    Account(string n, double b) {
        owner = n;
        balance = b;
    }

    void show() {
        cout << owner << " has $" << balance << endl;
    }
};

int main() {
    Account a1("Ali", 5000);
    Account a2("Sara", 8000);
    a1.show();
    a2.show();
    return 0;
}
Output: Ali has $5000 Sara has $8000

4. Copy Constructors

Definition: A copy constructor is a constructor that creates a new object as a copy of an existing object of the same class. It takes a reference to an object of the same class as its parameter.

Syntax

ClassName(const ClassName &obj) {
    // copy members from obj
}

When Is It Called?

  • When an object is initialized from another object: ClassName obj2 = obj1;
  • When an object is passed by value to a function.
  • When an object is returned by value from a function.

Types

TypeDescription
Default copy constructorAutomatically provided by the compiler; performs a shallow copy (copies member values directly).
User-defined copy constructorWritten by the programmer to perform a deep copy (e.g., allocating new memory for pointers).

Real-Life Example

Photocopying a document: the copy has the same content as the original but is a separate physical object.

Code Example (Deep Copy)

#include <iostream>
using namespace std;

class Box {
public:
    int *data;

    Box(int v) {
        data = new int(v);
    }

    Box(const Box &other) {          // copy constructor
        data = new int(*(other.data));
    }

    void show() {
        cout << "Value: " << *data << endl;
    }

    ~Box() { delete data; }
};

int main() {
    Box b1(50);
    Box b2 = b1;                      // invokes copy constructor
    b1.show();
    b2.show();
    return 0;
}
Output: Value: 50 Value: 50

5. Constructor Overloading

Definition: Constructor overloading means defining multiple constructors in the same class with different parameter lists. The compiler chooses the appropriate constructor based on the arguments provided at object creation.

Syntax

class ClassName {
public:
    ClassName() { }
    ClassName(int a) { }
    ClassName(int a, int b) { }
};

Real-Life Example

Booking a hotel room: you may book with only a name, or with name and number of nights, or with name, nights, and room type. Different sets of information are accepted.

Code Example

#include <iostream>
using namespace std;

class Room {
public:
    string guest;
    int nights;
    string type;

    Room() { guest = "None"; nights = 0; type = "Standard"; }
    Room(string g) { guest = g; nights = 1; type = "Standard"; }
    Room(string g, int n, string t) { guest = g; nights = n; type = t; }

    void show() {
        cout << guest << " | " << nights << " nights | " << type << endl;
    }
};

int main() {
    Room r1;
    Room r2("Ali");
    Room r3("Sara", 3, "Deluxe");
    r1.show();
    r2.show();
    r3.show();
    return 0;
}
Output: None | 0 nights | Standard Ali | 1 nights | Standard Sara | 3 nights | Deluxe

6. Destructors

Definition: A destructor is a special member function that is automatically called when an object is destroyed (goes out of scope or is explicitly deleted). It is used to release resources such as memory, file handles, or network connections.

Key Characteristics

  • Has the same name as the class, prefixed with a tilde (~).
  • Takes no parameters and has no return type.
  • Only one destructor per class (cannot be overloaded).
  • Called in reverse order of object creation.

Syntax

~ClassName() {
    // cleanup code
}

Real-Life Example

When you check out of a hotel room, the room is cleaned and prepared for the next guest. The destructor performs a similar cleanup when an object is no longer needed.

Code Example

#include <iostream>
using namespace std;

class File {
public:
    File() { cout << "File opened" << endl; }
    ~File() { cout << "File closed" << endl; }
};

int main() {
    File f1;
    cout << "Using file..." << endl;
    return 0;
}
Output: File opened Using file... File closed

7. Data Encapsulation

Definition: Encapsulation is the bundling of data (variables) and the methods (functions) that operate on that data into a single unit (a class). It also restricts direct access to some of the object's components, protecting data from unauthorized modification.

Real-Life Example

A capsule medicine: the medicine (data) is enclosed within a protective shell (class), and it can only be released in a controlled manner (through member functions).

Diagram

+--------------------------------+ | CLASS: BankAccount | | ------------------------------| | Private (hidden data): | | balance | | | | Public (controlled access): | | deposit(amount) | | withdraw(amount) | | getBalance() | +--------------------------------+

Code Example

#include <iostream>
using namespace std;

class BankAccount {
private:
    double balance;

public:
    void deposit(double amt) {
        if (amt > 0) balance += amt;
    }
    void withdraw(double amt) {
        if (amt > 0 && amt <= balance) balance -= amt;
    }
    double getBalance() { return balance; }
};

int main() {
    BankAccount acc;
    acc.deposit(1000);
    acc.withdraw(300);
    cout << "Balance: $" << acc.getBalance() << endl;
    return 0;
}
Output: Balance: $700

8. Access Specifiers: public, private, protected

Definition: Access specifiers control the visibility of class members. They determine which parts of a program can access a class's data and functions.

Types

SpecifierAccessible FromPurpose
publicInside class, outside class, derived classesOpen access; used for interfaces and methods
privateOnly within the classHidden data; default for class members
protectedWithin class and derived classesControlled inheritance-based access

Access Diagram

Inside Outside Derived Class Class Class +----------+ | | | | public | YES YES YES | private | YES NO NO | protected| YES NO YES +----------+

Real-Life Example

  • public – A car's accelerator pedal (accessible to driver).
  • private – The engine's internal wiring (hidden from driver).
  • protected – Service panel accessible only to authorized mechanics (derived types).

Code Example

#include <iostream>
using namespace std;

class Vehicle {
protected:
    int speed;

public:
    void setSpeed(int s) { speed = s; }
};

class Car : public Vehicle {
public:
    void show() {
        cout << "Speed: " << speed << endl;   // protected accessible
    }
};

int main() {
    Car c;
    c.setSpeed(80);
    c.show();
    return 0;
}
Output: Speed: 80

9. Getter and Setter Functions

Definition: Getter (accessor) functions return the value of a private data member. Setter (mutator) functions assign a new value to a private data member. They provide controlled access to encapsulated data.

Syntax

returnType getMember() { return member; }
void setMember(dataType value) { member = value; }

Real-Life Example

A television's volume can be changed only through the remote's volume button (setter) and checked via the display (getter), while the internal speaker circuit remains hidden.

Code Example

#include <iostream>
using namespace std;

class Person {
private:
    string name;
    int age;

public:
    void setName(string n) { name = n; }
    string getName() { return name; }

    void setAge(int a) {
        if (a > 0) age = a;      // validation
    }
    int getAge() { return age; }
};

int main() {
    Person p;
    p.setName("Ali");
    p.setAge(25);
    cout << p.getName() << " is " << p.getAge() << " years old." << endl;
    return 0;
}
Output: Ali is 25 years old.

10. This Pointer

Definition: The this pointer is an implicit pointer available inside every non-static member function. It points to the current object that invoked the function.

Uses of this Pointer

  • To distinguish between a data member and a parameter with the same name.
  • To return the current object from a member function.
  • To access members of the current object through a pointer.
  • To pass the current object to another function.

Real-Life Example

When a person says "my name," the word "my" refers to the person currently speaking. Similarly, this refers to the current object.

Code Example

#include <iostream>
using namespace std;

class Student {
private:
    string name;

public:
    void setName(string name) {
        this->name = name;       // this distinguishes member from parameter
    }
    string getName() { return name; }

    Student& getSelf() { return *this; }
};

int main() {
    Student s;
    s.setName("Sara");
    cout << s.getName() << endl;
    return 0;
}
Output: Sara

11. Static Data Members and Static Member Functions

Definition: A static data member belongs to the class rather than to any specific object. Only one copy exists and it is shared by all objects. A static member function belongs to the class and can be called without creating an object. It can only access static members.

Key Points

  • Static data members must be defined outside the class.
  • Static member functions do not have a this pointer.
  • Accessed using the class name: ClassName::member.

Real-Life Example

The number of students enrolled in a university is common to all students; it is a property of the university, not of any single student. This is a static data member.

Code Example

#include <iostream>
using namespace std;

class Student {
public:
    static int totalCount;          // shared data member

    Student() { totalCount++; }

    static void showCount() {       // static member function
        cout << "Total students: " << totalCount << endl;
    }
};

int Student::totalCount = 0;        // definition outside class

int main() {
    Student s1, s2, s3;
    Student::showCount();           // called without object
    return 0;
}
Output: Total students: 3

12. Constant Data Members and Constant Member Functions

Definition: A constant data member is a data member whose value cannot be modified after initialization. A constant member function is a function that guarantees not to modify any data members of the object. It is declared with the const keyword.

Rules

  • Constant data members must be initialized using an initializer list in the constructor.
  • A constant member function can be called on both constant and non-constant objects.
  • A non-constant member function cannot be called on a constant object.

Real-Life Example

A person's date of birth (constant) cannot change, while their age (non-constant) changes each year. A function that reads the date of birth must be declared constant.

Code Example

#include <iostream>
using namespace std;

class Person {
private:
    const int id;                 // constant data member
    int age;

public:
    Person(int idVal, int ageVal) : id(idVal), age(ageVal) { }

    int getID() const { return id; }     // constant member function
    int getAge() const { return age; }
};

int main() {
    Person p(101, 25);
    cout << "ID: " << p.getID() << ", Age: " << p.getAge() << endl;
    return 0;
}
Output: ID: 101, Age: 25

13. Array of Objects

Definition: An array of objects is a collection of objects of the same class stored in contiguous memory, accessed using an index. Each element is a separate object with its own set of data members.

Syntax

ClassName arrayName[size];
ClassName arrayName[size] = { Object1, Object2, ... };

Real-Life Example

A classroom contains multiple students, each with their own name, roll number, and marks. These are naturally represented as an array of Student objects.

Code Example

#include <iostream>
using namespace std;

class Student {
public:
    string name;
    int marks;

    void set(string n, int m) { name = n; marks = m; }
    void show() { cout << name << ": " << marks << endl; }
};

int main() {
    Student list[3];
    list[0].set("Ali", 85);
    list[1].set("Sara", 92);
    list[2].set("John", 78);

    for (int i = 0; i < 3; i++)
        list[i].show();

    return 0;
}
Output: Ali: 85 Sara: 92 John: 78

Array of Objects Diagram

Part B: Practical Topics

Practical 1: Implementing Default and Parameterized Constructors

#include <iostream>
using namespace std;

class Book {
private:
    string title;
    double price;

public:
    Book() {                         // default constructor
        title = "Untitled";
        price = 0.0;
    }

    Book(string t, double p) {       // parameterized constructor
        title = t;
        price = p;
    }

    void show() {
        cout << title << " - $" << price << endl;
    }
};

int main() {
    Book b1;                         // default
    Book b2("C++ Primer", 45.50);    // parameterized
    b1.show();
    b2.show();
    return 0;
}
Output: Untitled - $0 C++ Primer - $45.5

Practical 2: Implementing Copy Constructors

#include <iostream>
using namespace std;

class Number {
private:
    int value;

public:
    Number(int v) { value = v; }

    Number(const Number &n) {       // copy constructor
        value = n.value;
        cout << "Copy constructor called" << endl;
    }

    void show() { cout << "Value: " << value << endl; }
};

int main() {
    Number n1(10);
    Number n2 = n1;                  // invokes copy constructor
    n1.show();
    n2.show();
    return 0;
}
Output: Copy constructor called Value: 10 Value: 10

Practical 7: Using the this Pointer

#include <iostream>
using namespace std;

class Counter {
private:
    int count;

public:
    Counter(int count) {
        this->count = count;        // resolves name conflict
    }

    Counter& increment() {
        count++;
        return *this;               // returns current object
    }

    void show() { cout << "Count: " << count << endl; }
};

int main() {
    Counter c(5);
    c.increment().increment().increment();    // chained calls
    c.show();
    return 0;
}
Output: Count: 8

Practical 8: Implementing Static Members and Functions

#include <iostream>
using namespace std;

class Bank {
public:
    static int accountCount;
    static double interestRate;

    static void setInterest(double r) { interestRate = r; }
    static void showInfo() {
        cout << "Accounts: " << accountCount

Output: Accounts: 3 | Rate: 6.5%

Practical 9: Working with Constant Data Members and Functions

#include <iostream>
using namespace std;

class Circle {
private:
    const double PI;             // constant data member
    double radius;

public:
    Circle(double r) : PI(3.14159), radius(r) { }

    double area() const {        // constant member function
        return PI * radius * radius;
    }
    double circumference() const {
        return 2 * PI * radius;
    }
};

int main() {
    Circle c(7);
    cout << "Area: " << c.area() << endl;
    cout << "Circumference: " << c.circumference() << endl;
    return 0;
}
Output: Area: 153.938 Circumference: 43.9823
